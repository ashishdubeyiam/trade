This project aimed to develop a comprehensive machine learning pipeline for fraud detection, complete with a user interface to facilitate data input and results visualization, and to evaluate the performance of various classification models within this framework. The endeavor successfully resulted in a functional end-to-end system where transaction data can be uploaded, processed through configurable preprocessing steps, used to train multiple machine learning models (Logistic Regression, Decision Tree, Random Forest, and a placeholder for an ANN), and subsequently evaluate their performance, with outcomes displayed through the web UI.
